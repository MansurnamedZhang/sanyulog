# 系统与编辑工作台优化

用户重点：编辑效率与稳定性。保持中文连续 Notebook、管理员创建多账号、七天登录、局域网 HTTP、服务器加密保存及现有数据契约。

## 本轮设计

- 保留绿色品牌和三栏工作台，统一字号、间距、控件及选中反馈。窄屏使用抽屉导航与列表/正文切换，2K 横屏继续利用可用宽度。
- 视图菜单提供舒适/紧凑列表与三档阅读字号，按账号在浏览器记忆。重新打开恢复当前工作空间上次阅读的笔记。
- 搜索缓存每份记录的索引，合并连续输入；列表按记录 ID 更新，限制摘要长度，保存后保留列表位置、搜索框焦点及正文编辑器。
- 导航、视图与专注等本地操作即时响应；切换到其他笔记、工作空间、导出及账号操作仍等待当前保存完成。
- 状态读取批量加载笔记、时间线和附件，消除随记录数增长的逐条查询；保持 SQLite、PostgreSQL、加密解密与账号隔离行为。

## 实施与验收

1. 先为搜索缓存、摘要、视图参数和批量状态读取补充失败用例，再实现独立模块及存储查询优化。
2. 接入按 ID 更新的列表、搜索调度、视图设置及阅读恢复，整理工作台样式和操作反馈。
3. 在独立演示数据中验证多关键词、特殊字符、即时本地操作、保存失败、刷新恢复与账号切换。
4. 覆盖 320–2560px 横屏/竖屏，保留表格多选增删、滚动稳定、Markdown/公式/流程图及图片/PDF 导出回归。
5. 完成 Node、Python、格式和浏览器检查，提交 GitHub；精确提交 Checks 通过后备份并部署，核对线上哈希与访问控制。

不改变数据库结构和认证/加密协议；性能结论以查询次数和实测证据为准。
