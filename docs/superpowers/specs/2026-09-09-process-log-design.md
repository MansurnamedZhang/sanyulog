# 过程簿：本地过程记录工具

用户已确认：个人使用、中文、本地网页与数据库、手动记录。

## 使用流程
项目 → 实验或调试记录 → 带时间的操作、观察、问题、结论。标题必填，目标、参数、标签、结果、结论、下一步均选填。记录支持编辑、删除、复制和关联比较。附件支持上传、下载、图片预览及删除。通用、LoRA 训练、工作流调试模板可编辑并持久保存。

## 架构与数据
Python 3.12 标准库 HTTP 服务只监听 127.0.0.1，SQLite 保存项目、记录、时间线、模板和附件元数据，附件按随机 ID 保存至 data/attachments。静态 HTML/CSS/JavaScript 实现三栏工作台和窄屏布局，无外部 CDN，无在线服务依赖。

## 可靠性
显式保存；未保存内容离开时提醒；表单失败保留输入；浏览器本地存储仅用于草稿。数据库事务写入，编辑带版本号防止多窗口静默覆盖。完整 ZIP 备份包含数据库及附件；恢复前校验 schema、路径和文件引用，生成恢复前备份，恢复失败回滚。仅同源请求允许修改，附件下载不能执行 HTML。

## 验收
真实临时数据库与 HTTP 测试覆盖 CRUD、搜索、复制关联、版本冲突、附件、Markdown 导出、备份恢复、无效备份拒绝、重开数据库后数据保留。JavaScript 语法检查；启动服务并请求首页。交付启动脚本、说明文档和本地入口。
