# Notebook 连续记录

用户已确认：连续单元格，Markdown/代码/日志/图片附件，自由追加、插入、移动、删除，自动保存，Shift+Enter 保存并进入下一格。仅记录代码，不执行代码。已有记录与附件必须保留。

## 数据与兼容
SQLite schema v2 添加 notebooks(record_id, cells JSON)。单元格包含 id/type/source/language/attachment_ids。record.version 保护正文和元数据的整个保存事务。旧时间线按创建顺序转为 Markdown 格（保留分类标题与原文），旧附件转为附件格；旧表保留，旧 API 的时间线操作同步 notebook。启动迁移前保存备份；恢复支持 v1 和 v2 备份，并校验单元格类型、ID、文本、附件所属关系。

## 界面和可靠性
正文成为详情主区域，元数据折叠。Markdown 提供编辑/预览，代码和日志保留原始空白，附件单元格内展示图片及下载链接。支持 Markdown 标题、强调、列表、引用、表格、链接和代码块，原始 HTML 作为文字显示，外链只支持 http/https/mailto，不自动请求远程图片。

按笔记本维护保存队列，输入 800ms 后保存。保存期间仍可输入；后续输入以新版本接续保存，成功响应不重画编辑器、不丢焦点。切换笔记本前 flush；失败保留浏览器草稿并阻止切换。版本冲突停止重试，不覆盖他人修改。刷新后恢复草稿。单元格删除需确认，可撤销最后一次删除。

## 验证
临时 v1 数据库迁移幂等与附件保留；单元格排序/编辑/空白/空格保存；多窗口冲突；旧备份恢复；无效引用与数据拒绝；Markdown 安全输出；保存排队、保存失败和重试。运行现有回归与新增测试，启动后检查静态资源与 API。
