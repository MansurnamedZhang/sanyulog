# 独立数据库块

用户决定保留现有 CSV 表格原样，新增 Notion 风格数据库；本轮选定表格视图与属性管理。

- 新增第六种 database 单元格，名称「数据库」，与旧表格独立。
- 支持文本、单选、多选、数字、日期、复选框属性；选项有稳定 ID 和颜色，改名不丢选择。
- 支持属性增删、改名、调整顺序及类型；类型变更或删除涉及数据时需明确确认。
- 支持记录增删、多选删除；单格文字自动换行，换段/粘贴保留在当前格。
- 搜索、一个属性条件筛选、一个属性排序；视图设置保存，搜索和分页不持久化。
- 数据独立 JSON 保存在 cell.source，复用当前账号隔离、加密、自动保存与备份，禁止接触真实用户数据。
- 上限 50 属性、1000 记录、每属性 100 选项；单格文本 20000 字符；遵守原 source 500000 字符、笔记本 1.5MB 限制。
- 以稳定 32 位小写十六进制 ID 关联属性、记录、选项；服务端严格验证，非法更新原子拒绝。
- CSV/Markdown/整页 PDF 导出使用可读标签；JSON 在账号备份内保留全部结构；导出全部记录，不受当前视图筛选限制。
- 320/390/1440/2560 宽屏与竖屏无页面横向溢出；增加记录和属性时保留滚动位置，编辑过程中不重建整页。
- 不改旧 CSV 表格数据、界面、事件和导入/导出逻辑；不包含看板、关系、公式、协作和公开分享。
