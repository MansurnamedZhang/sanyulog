# Notebook Implementation Plan

**Goal:** 将已确认的记录详情改为连续 Notebook 编辑器。
**Architecture:** SQLite notebooks + existing record optimistic version; pure JS autosave queue and safe Markdown renderer; notebook UI module integrated into existing projects/templates/backup UI.
**Spec:** docs/superpowers/specs/2026-09-09-notebook-design.md

- [x] 测试先行：v1 fixture 迁移、重开不重复、单元格原子保存、排序、冲突、附件引用验证、v1/v2 备份恢复。
- [x] store.py 添加 notebooks 表及迁移；record 读取/更新返回 cells；Markdown 导出和旧时间线 API 兼容；server.py 注册新模块静态路径。
- [x] tests/notebook.test.mjs：渲染 XSS 防护与结构、保存队列输入竞态与失败保留。实现 static/notebook-core.mjs 独立逻辑。
- [x] static/notebook.js：单元格增删移动、编辑/预览、附件插入、自动保存、Shift+Enter、元数据折叠；app.js 接入。
- [x] 回归测试、独立审查、现有数据备份后重启、首页资源检查与使用说明。
